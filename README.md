# Mera Area

Mera Area is a local-language community problem-solving app for India. This repository contains the Expo mobile MVP under `artifacts/mera-area-mobile`.

## Start

```bash
pnpm install
pnpm --filter @workspace/mera-area-mobile run dev
```

The preview opens in Expo Go. The MVP runs in demo mode with seeded local data and AsyncStorage persistence. Supabase migration files and setup notes are in `artifacts/mera-area-mobile/supabase/` and its README.
